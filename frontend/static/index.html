Kernel heap

How it works

The heap is a first-fit free list: free blocks are kept in address order, a request takes the first block that fits and splits off the rest, and freed blocks merge with free neighbours. A header on every block records its size and a magic number, so double and foreign frees are refused. Try memtest 4096 and watch the graph.

Programs

Rust programs in kernel/src/programs/ — each runs as its own task

Write your own

  1. Copy kernel/src/programs/template.rs to myprog.rs and edit main.
  2. Add mod myprog; and one line to PROGRAMS in programs/mod.rs.
  3. Restart the panel (scripts/frontend.sh); it rebuilds the kernel and your program appears here.

Micro-OS

An educational operating-system kernel written in Rust for the CA-6 Operating Systems project. It boots on an emulated RISC-V computer (QEMU virt, OpenSBI firmware) inside WSL, and makes OS mechanisms visible instead of hiding them.

Bootentry.S → kmain, command line from the device tree
Traps & timertrap.S saves registers; 1 ms SBI timer drives preemption
Taskstask control blocks, 16 KiB stacks with overflow canaries
SchedulerRound Robin, Priority, Priority + aging, MLFQ
SynchronizationIRQ spinlock, spinlock, blocking mutex, semaphore, deadlock detection
Memory16 MiB first-fit free-list heap; bump and best-fit for comparison
System interfacesys:: API, programs, this shell

Docs: docs/architecture.md, docs/design.md, docs/testing.md, docs/writing-programs.md.
