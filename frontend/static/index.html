              NEXUS OS
              
          
              NEXUS is the desktop of Micro-OS, an educational operating-system kernel written in Rust for the CA-6 Operating Systems project. The kernel boots on an emulated RISC-V computer (QEMU virt, OpenSBI firmware) inside WSL; this desktop runs in your browser and draws only what the kernel reports.
              
          
              
            
              Kernel
              monolithic, supervisor mode, one hart; not a microkernel
              
            
              Boot
              entry.S → kmain, command line from the device tree
              
            
              Traps and timer
              trap.S saves registers; 1 ms SBI timer drives preemption
              
            
              Tasks
              task control blocks, 16 KiB stacks with overflow canaries, up to 512 tasks
              
            
              Scheduler
              RR, Priority, Priority + aging, MLFQ, FCFS, SJF, SRTF, HRRN
              
            
              Synchronization
              IRQ spinlock, spinlock, blocking mutex, semaphore, deadlock detection; no message-passing IPC
              
            
              Memory
              16 MiB first-fit free-list heap; bump and best-fit for comparison
              
            
              Storage
              none: no file system; Files shows the project on the host
              
            
              Programs
              linked into the kernel; Code rebuilds the kernel on the host with cargo
